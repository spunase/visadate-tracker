# Checkpoint Prompt Template

Use this pattern at the end of each phase.

## Summary
- What was produced
- What design choices were made
- What assumptions were made

## Risks
- What may still be wrong
- What is still uncertain

## Decision needed
Choose one:
1. Approve and continue
2. Revise this phase
3. Branch into an alternative direction

## Feedback request
Please comment on:
- spacing
- hierarchy
- overall feel
- fit to the reference
- anything that feels off
